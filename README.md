# Household Meal Planner

A mobile-first meal planning and grocery shopping web app for households.

This app helps a couple or family plan weekly lunches and dinners, choose meals from a shared meal library, and automatically generate a grocery list from the selected meals.

## Features

- Mobile-first layout designed for phone use
- Weekly lunch and dinner planner
- Reusable meal library
- Meal detail pages with ingredients
- Auto-generated grocery list
- Grocery items grouped by category
- Planner state saved in localStorage
- Bottom navigation for app-like usage

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- localStorage for temporary persistence

## Current Status

This is an early MVP version.

The app currently uses mock meal data and browser localStorage. The next major milestone is adding a shared database so multiple household members can use the same meal plan online.
